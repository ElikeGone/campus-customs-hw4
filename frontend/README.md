# Campus Customs frontend

The React + Vite + TypeScript storefront for the Campus Customs shop. See the [project README](../README.md) for the full setup, including the data pack, environment variables, and backend.

```bash
npm install
npm run dev     # http://localhost:5173 (the backend must be running on port 8000)
npm run build   # type-check and production build
npm run lint
```
